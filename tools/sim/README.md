# محاكاة Roblox لاختبار السكربت

لأن Roblox Studio غير متاح في بيئة التطوير الآلية، هذه محاكاة بسيطة (`mock.lua`) لواجهة Roblox تنفّذ السكربت الحقيقي وتتحقق من:
- أن كل خاصية/دالة مستخدمة موجودة فعلاً في الـ API (من `API-Dump.json`)
- تشغيل بناء الماب وحلقات اللعب (الأعداء، الزعيمين، الصواعق، المدافع، المتجر، الإنجازات، الدفع...)

السيناريوهات: `scenario_gameplay.lua` · `scenario_bosses.lua` (قتال الزعيمين حتى الفوز) · `scenario_longrun.lua` · `scenario_monetization.lua`
(للأخير غيّر معرّفات `MONETIZATION` إلى أرقام وهمية أولاً).

**لا تغني عن تجربة Studio**: الفيزياء وإحساس اللعب والتصادم غير محاكاة.
