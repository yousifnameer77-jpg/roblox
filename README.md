# 🌈 جزر السماء — Sky Islands (ماب روبلوكس)

ماب مغامرة/أوبي كامل يُبنى **بالكود بالكامل** (لا تحتاج أي موديلات أو أصول خارجية).

## طريقة التشغيل (الأسهل)
1. افتح Roblox Studio وأنشئ مكان جديد (Baseplate أو Empty، السكربت يحذف الـ Baseplate تلقائياً).
2. من `Explorer` اضغط **+** بجانب `ServerScriptService` ← `Script`.
3. انسخ محتوى الملف `src/SkyIslands.server.lua` والصقه داخل السكربت.
4. اضغط **Play** — الماب يُبنى تلقائياً خلال ثوانٍ.
5. لحفظ العملات: فعّل `Game Settings ← Security ← Enable Studio Access to API Services` (اختياري).

(بديل: استخدم Rojo — الملف `default.project.json` جاهز: `rojo serve`.)

## مراحل الماب
| المرحلة | الوصف |
|---|---|
| 🏝 الهب | جزيرة بداية مع نافورة، بلورات عائمة تدور، 4 شلالات، يراعات وبوابة |

| 🔮 جسر الزجاج السحري | 10 صفوف زجاج: بلاطة حقيقية وبلاطة مزيّفة تنكسر عند لمسها (التوزيع يتغير في كل سيرفر) |
| ⚡ برج النيون | 5 منصات نيون وجامبينج باد (Jump Pad) للأعلى |
| 🏆 القمة | كأس ذهبي + ألعاب نارية + مكافأة 50 عملة |

## المتجر 🛒 والأعداء 👾 والأصوات 🔊
- **المتجر** في الهب (يسار النافورة): اقترب من أي عرض واضغط **E** للشراء بالعملات المجموعة. المشتريات تُحفظ:
  حذاء السرعة (30) · نطّة عالية (40) · قلب إضافي (35) · مغناطيس العملات (60) · رفيق متوهج (50) · ذيل ناري (25).
- **الأعداء:** Slime يمشي ذهاباً وإياباً، Drone يطير في دوائر، Ghost شبح يعبر جسر الزجاج،
  و3 حرّاس يدورون حول الكأس في القمة. ادعس على رأس العدو لتقتله (+3 عملات ويعود بعد 12 ثانية)
  وإلا تتضرر وتنقذف للخلف. الحراس لا يموتون ويجب تفاديهم.
- **الأصوات:** مؤثرات للعملات ونقاط الحفظ والقفز والدفع وكسر الزجاج والضرر والشراء والفوز.
  تستخدم أصوات Roblox المدمجة؛ عدّل الجدول `SFX` أعلى السكربت لاستبدالها بأرقام من Creator Store.
  موسيقى الخلفية: ضع أرقام الموسيقى في الجدول `MUSIC` (فارغ افتراضياً).

## الميزات والمؤثرات
- 5 نقاط حفظ (Checkpoints) مع انفجار ألوان عند الوصول + لوحة ترتيب (Stage / Coins / Wins) وحفظ تلقائي
- عملات دوّارة قابلة للجمع مع شرارات عند جمعها (تعود بعد 15 ثانية)
- ذيل ملوّن (Trail) خلف كل لاعب
- شفق قطبي متغير الألوان في السماء، دورة نهار وليل، ضباب جوي، Bloom، غيوم وجزر ديكور بعيدة
- بلورات نيون مضيئة، ثلج وجزيئات بنفسجية في المراحل الأخيرة
- إشعارات على الشاشة عند الوصول لنقطة حفظ أو الفوز
- سرعة المشي 18 وقوة القفز 55 (قابلة للتعديل أعلى السكربت)

## تعديل سريع
- مواقع/عدد الجزر: الأقسام `المرحلة 1..4` داخل السكربت.
- صعوبة المراحل: سرعة العصي (`speed`) وفترة المنصات (`TweenInfo`).
